誠品活動頁入稿合併工具

A 活動頁範本 ＋ B 商品資料 → 產出可直接貼回的完整 Code

怎麼運作
  • A 貼「整段活動頁 Code」或「一個 <li> 範本」都可以。工具會抓 A 裡第一個 <li> 當範本。
  • B 逐筆套進範本,填入對應欄位(href、img src、h4、p、data-product-id、data-price、data-discount)。
  • 範本的排版、class、周邊文字原樣保留,只換值。
  • 折數 100 或空白 → data-discount 留空。圖檔連結照 B 原樣,不改尺寸。

A｜活動頁範本 Code

貼整段活動頁,或貼一個 <li> 區塊當範本。

B｜商品資料

一列一個商品,用 Tab 分欄(從 Excel 複製即可)。欄位順序 ↓
