📌 使用說明
  • 上傳設計師提供的 index.html（空版或前次活動頁）
  • 中文定刊（愛讀報、誠品選書報、輕漫情報誌）屬於活動頁結構，請使用本分頁產出入稿 DATA；完成後若要寄 EDM，再使用「活動頁轉 EDM」。
  • 工具自動辨識空白 index 中的商品、Banner、Tabs 等可入稿槽位，產出 入稿DATA.xlsx（PM 可輸入欄位預設為文字格式，避免商品ID長數字被轉格式）
  • 下載後交給 PM 填寫商品資料，完成後進行步驟 3
  • 商品資料請先填「商品ID」：一般商品請填商品頁網址 /product/ 後方完整商品 ID，例如 10052314312683059958003，價格會依此 ID 連動；若價格類型選「自訂價格文案」且不需要價格連動，商品ID 可留空
  • 「連結URL」可留空：留空時系統會自動導到商品頁；若要導到策展頁、品牌頁、組合頁或其他活動頁，才填完整 URL
  • 小標題可改字：若 Excel 的【小標題】對應到 HTML 畫面上的 Tabs / h3 / 小區標題，PM 修改後合板會同步回填；若只是工具分類名稱，則不影響畫面
  • 價格類型：支援折,特價$、推薦價$、折／特價$、特價$、結帳價$、自訂價格文案；「結帳價$」若有填自訂價格文案，會優先固定顯示該金額，不吃商品ID價格
  • ⚠️ Excel 中的「系統對位表」為工具回填專用，請勿刪除、移動或修改

電子報 / EDM 自動入稿｜產出 EDM 入稿表
支援雛形：流行風尚報、風格文具報、生活雜貨報、饗食報 / 食品報。上傳 EDM HTML 後產出專用入稿 DATA。中文定刊（愛讀報、誠品選書報、輕漫情報誌）請改用「活動頁自動入稿」。
📌 EDM 模式說明
  • EDM 多為 table width=700 排版，和活動頁 div / block 架構不同，因此獨立成 EDM 分頁。
  • EDM 價格多為寫死文字，建議直接填「價格文字」，例如 8折,NT$1,350、結帳價$4,480、特價$1,060。
  • 食品報價格可混用格式：若需原價劃線可填 <s>$2,249</s> $<b>1,799</b>；若只有單一售價，可填 $120、特價$588 或促案文字。
  • 商品ID 在 EDM 模式為選填；若連結URL留空但商品ID有填，才會自動產商品頁連結。
  • 目前為 beta 雛形，會先抓圖片、連結、標題 / 品名、內文 / 賣點、價格文字與底部 Banner；不同報別後續可再補細部版型命名。
  • 中文定刊（愛讀報、誠品選書報、輕漫情報誌）不是 700px table EDM，請改用「活動頁自動入稿」產 DATA，再用「活動頁轉 EDM」寄送。

📌 活動頁轉 EDM 使用說明
  • 先上傳完成版 index.html，系統會優先讀取 og:url，自動帶入活動年份、活動 ID、正式活動頁連結與 EDM 圖片路徑。
  • 再用 GoFullPage / FireShot 截完整活動頁長圖，上傳到本工具後自動裁切成 edm_1.jpg、edm_2.jpg...
  • 系統預設會移除截圖底部的活動頁頁尾資訊，避免和 edm.html 自帶的 EDM 頁尾重複。
  • 產出的 edm.html 內圖片路徑會使用線上網址，不使用本機路徑。
  • 下載包內會包含 edm.html、edm/ 圖片資料夾與上傳提醒文字檔。
⚠️ 重要提醒：正式寄送前，請先將下載包內的 edm 圖片資料夾上傳到 Cyberduck / Filemage / 小鴨對應活動資料夾底下；否則收件者會看不到 EDM 圖片。
